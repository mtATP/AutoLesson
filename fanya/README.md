# AutoLesson 泛雅版（v0.1 开发中）

> **开发中：泛雅版仍在开发，尤其自动练习（`practice` / `auto`）仍有已知 bug，暂不建议无人值守使用。**
> 目前建议优先使用视频模式，并在有人看管时运行。

> 仅用于个人学习辅助。超星/泛雅可能禁止自动化操作，使用本工具可能带来账号风险；

智慧树版在并列目录 `zhihuishu/`，本目录只放泛雅（超星泛雅/学习通）平台相关代码。

## 命令

在项目根目录运行（Windows 项目目录同样适用）：

```bat
:: 只读探针：看 OCR 坐标和标注图
python -m fanya probe
python -m fanya probe --image 泛雅课程页.png

:: 只读扫描当前页：目录任务点 + 当前标题/标签/进度
python -m fanya scan
python -m fanya scan --all

:: 扫描并列出待处理任务点，不点击
python -m fanya run --dry-run
python -m fanya run --dry-run --max-items 5

:: 第一版视频挂机
python -m fanya run
python -m fanya run --max-items 1
```

`--all` 会滚动右侧目录并合并多页；`--image` 用静态截图做离线规划，不会点击。

## 识别依据

目录节点（`#coursetree` / `.posCatalog`）形如：

```text
1.3.1 国防体制          <- 三级叶子，任务点
1.4 武装力量            <- 二级章节头，跳过
2 国家安全              <- 一级章节头，跳过
```

右侧状态列：

- 绿色勾（`.icon_Completed`）= 该知识点所有任务点已完成；
- 橙色数字（`.catalog_points_yi`）= 还有待完成任务点，数字为数量；
- 当前行是浅蓝渐变背景。

右下角 AI 助教（常态紫色徽章、悬停黄色星球）会盖住状态列。脚本按颜色
定位助教，只跳过状态列被它遮挡的目录行；这些行滚出遮挡后会重新读取，
助教下方的条目不会被误判成待完成。

目录滚动步长可在 `config.yaml` 的 `fanya` 区调整；如果只想让泛雅使用不同值，
可在 GUI 点“保存为当前平台专用”，生成 `config.fanya.yaml`：

```yaml
fanya:
  # 直接指定像素；>0 时优先
  scroll_step_px: 0
  # 按目录可视高度比例滚动；默认 55%，换分辨率/DPI 时优先调这个
  scroll_step_ratio: 0.55
  controls_wiggle: true
  progress_timeout_seconds: 15.0
  max_recoveries: 4
  controls_wiggle_interval_seconds: 10.0
```

当前视频页：

- 标题：内容区左上方最大字号文字；
- 标签：`1 视频` / `2 章节测验`；
- 完成提示：`任务点已完成`（绿色）；
- 进度：播放控制条左侧 `28:43 / 33:29`；
- 播放键：新视频先点画面中央的大灰播放键；播放中暂停后恢复点左下角，白色三角形=暂停中，两条竖线=播放中。

## 视频完成记录（重要）

泛雅目录的绿勾是**整个知识点的所有任务点**都完成才显示。视频看完了但章节测验/练习没做时，目录仍然没有绿勾，
所以不能只看目录判断视频是否完成。脚本会：

- 页面显示「任务点已完成」时，记录到 `runtime/fanya_state.json` 的 `videos`；
- 视频播放到结尾且平台标记完成时同样记录；
- 日志写 `视频完成记录: 3.3.1 ...（来源: ...；目录未打勾时以此记录/日志为准）`；
- 每次运行写独立的 `runtime/logs/fanya-YYYYmmdd-HHMMSS.log`。

下次运行即使目录仍无绿勾，也会先打日志/记录确认，再打开页面复核，不会把“视频已完成、练习未完成”误当成没看。

## 视频弹题

弹题覆盖在播放器上，结构是 `ans-videoquiz`：

```text
判断题 / 单选题
题干
A、对   B、错
[提交]  提交后出现 [继续]
```

处理流程：识别题型/题干/选项 → 大模型给答案 → 点选项 → 点提交 → 出现「继续」后点继续。
没有可用大模型时会默认选第一个选项并写警告，需人工复核。

## 已知限制

- 第一版只处理视频和视频中途弹题；不处理章节测验/作业/文档，目录里的测验/文档任务点会因为没有「视频」标签而跳过。
- 目录节点目前要求编号至少两级（如 `1.3.1`）；没有编号的「阅读/问卷调查」叶子暂不处理。
- 播放器坐标按 2559×1540、浏览器缩放 100% 的样本标定；换了分辨率/缩放需要实测调整。
- 视频页的「继续上次播放」等弹窗只做了通用文字点击，复杂弹窗需要样本继续补。
